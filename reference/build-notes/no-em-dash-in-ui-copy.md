No em dashes (—) in user-visible copy in the MS prototypes — agent chat messages, warning
notices, confirm cards, labels. Split into two sentences or use a comma instead.

**Why:** Raashi flagged an em dash in the pause confirm card ("no em dash") on the
[[cco-aug28-experience-workflows]] builds; it reads as un-product-like copy.

**How to apply:** When writing any conversation/notice copy in these builds, prefer
"Sentence one. Sentence two." over "clause — clause". Code comments are fine.
